# Build Spec for Course
- database schema: `.\database\course.sql`
- menu group: 課程管理 Course
- generated by `/crud` — grounded to the **actual** scaffold (Partner/CourseGroup/AppRole), not the
  idealized `spec/sample1.spec.md`. Idealized extras (copy action, QR code, print-PDF, ClassSection
  links, inline sub-panels) are **out of scope** — their tables/features are not in this scaffold.

## Summary

`Course` (課程) is the central content entity: a training course offered by a `Partner`, optionally
grouped by a `CourseGroup`, with a `PublishStatus`. It carries scheduling dates, pricing, and a large
body of descriptive text. It is the **first feature in this scaffold with outbound FKs** and the
second (after `AppRole`) with N-N relationships — it exercises both the multi-map FK-join read and the
delete-then-reinsert junction sync.

| Item | Detail |
|------|--------|
| Primary Key | `pkid` **int IDENTITY** (auto-generated `int`) |
| Foreign Keys | `Partner_pkid` → `Partner.pkid`; `CourseGroup_pkid` → `CourseGroup.pkid` (**nullable**); `PublishStatus_pkid` → `PublishStatus.pkid` |
| Required Fields | `Title`, `CourseId`, `ProdCourseId`, `FriendlyUrl`, `DisplayOrder`, `Partner_pkid`, `PublishStatus_pkid`, `ScheduleOn`, `ScheduleOff`, `Hour`, `ListPrice`, `LearningCredit`, `CanRepeat` |
| N-N Relationships | `CourseInCertification` (Course ↔ Certification); `CourseJobCategories` (Course ↔ JobCategory) |
| Primary-Foreign Links | `CourseFAQ`, `CourseRelatedLink`, `HotCourse`, `CourseInCertification` reference Course — child features **not built**, inbound link buttons **deferred** (as in `Partner.md`) |
| Query Filters | keyword (Title, OfficialTitle, CourseId, ProdCourseId, FriendlyUrl); Partner_pkid; CourseGroup_pkid; PublishStatus_pkid; ScheduleOn range; ScheduleOff range; CanRepeat |
| Default Sort | `DisplayOrder ASC, pkid ASC` |

Required (NOT NULL, excluding IDENTITY PK):
- `Title` — nvarchar(200)
- `CourseId` — varchar(50)
- `ProdCourseId` — varchar(50)
- `FriendlyUrl` — nvarchar(100)
- `DisplayOrder` — int
- `Partner_pkid` — smallint (FK)
- `PublishStatus_pkid` — tinyint (FK)
- `ScheduleOn` — date
- `ScheduleOff` — date
- `Hour` — smallint (DB default 0)
- `ListPrice` — decimal(9,0) (DB default 0)
- `LearningCredit` — decimal(9,1) (DB default 0)
- `CanRepeat` — bit (DB default 0)

Optional (nullable):
- `OfficialTitle` — nvarchar(300)
- `CourseGroup_pkid` — smallint (nullable FK → "無" option)
- `Material` — nvarchar(500)
- `Objective` — nvarchar(4000)
- `Target` — nvarchar(500)
- `Prerequisites` — nvarchar(4000)

- `TowardCertOrExam` — nvarchar(max)
- `Note` — nvarchar(4000)

internally, read back from the create response for navigation — same as `Partner`).

## Foreign Keys

List/Detail use the FK to display the related label; Form uses it to populate a `p-select`.

- **Partner_pkid** → `Partner.pkid` (**required**)
  - Alias `Partner_pkid AS PartnerPkid` in SELECT.
  - Nav object `Partner { Pkid, Name }` via LEFT JOIN; label = `Name`.
  - Lookup: `GET /api/lookups/partners` (exists) → `{ pkid, name }[]`, order `DisplayOrder ASC`.

- **CourseGroup_pkid** → `CourseGroup.pkid` (**nullable** — allow "無")
  - Alias `CourseGroup_pkid AS CourseGroupPkid`.
  - Nav object `CourseGroup { Pkid, Description }` via LEFT JOIN; label = `Description`.
  - Lookup: `GET /api/lookups/course-groups` (exists) → `{ pkid, description }[]`, order `pkid ASC`.

- **PublishStatus_pkid** → `PublishStatus.pkid` (**required**)
  - Alias `PublishStatus_pkid AS PublishStatusPkid`.
  - Nav object `PublishStatus { Pkid, Description }` via LEFT JOIN; label = `Description`.
  - Lookup: `GET /api/lookups/publish-statuses` (exists) → `{ pkid, description }[]`, order `pkid ASC`.

All three FK lookups already exist (`LookupsController` / `LookupRepository`). No new FK lookups needed.

## N-N Relationships

Both junctions are pure two-FK tables → managed with a multi-select picker + delete-then-reinsert sync
(the `AppRole ↔ AppUser` pattern via `AppUserRole`).

### CourseInCertification — Course ↔ Certification

Junction `CourseInCertification (Course_pkid int, Certification_pkid int)`, composite PK.

- **Related entity**: `Certification (pkid int IDENTITY, Partner_pkid smallint, Title nchar(100) NULL)`.
- **New lookup** `GET /api/lookups/certifications` → `{ pkid, label }[]` where
  `label = Partner.Name + ' - ' + RTRIM(Certification.Title)` (Title is `nchar` → **RTRIM**),
  ordered by `Partner.Name ASC, Certification.Title ASC`. JOINs `Partner` for the name.
- **Form (edit + new)**: `p-multiselect` (`[maxSelectedLabels]="9999"`, `[filter]="true"`).
- **Detail**: read-only list of selected labels.
- **Request field**: `CertificationPkids : List<int>`.
- **Read on GET-by-id**: `SELECT Certification_pkid FROM CourseInCertification WHERE Course_pkid=@Pkid`.
- **Sync (create + update)**: `DELETE FROM CourseInCertification WHERE Course_pkid=@Pkid;` then bulk
  INSERT each `(@Pkid, @CertificationPkid)` — inside the same transaction as the scalar write.

### CourseJobCategories — Course ↔ JobCategory

Junction `CourseJobCategories (Course_pkid int, JobCategory_pkid smallint)`, composite PK.

- **Related entity**: `JobCategory (pkid smallint IDENTITY, Description nvarchar(70) NOT NULL)`.
- **New lookup** `GET /api/lookups/job-categories` → `{ pkid, description }[]`, order `Description ASC`.
- **Form (edit + new)**: `p-multiselect` (`[maxSelectedLabels]="9999"`, `[filter]="true"`).
- **Detail**: read-only list of selected descriptions.
- **Request field**: `JobCategoryPkids : List<short>` (JobCategory pkid is `smallint`).
- **Read on GET-by-id**: `SELECT JobCategory_pkid FROM CourseJobCategories WHERE Course_pkid=@Pkid`.
- **Sync (create + update)**: `DELETE FROM CourseJobCategories WHERE Course_pkid=@Pkid;` then bulk
  INSERT each `(@Pkid, @JobCategoryPkid)` — same transaction.

## Query Filters

`POST /api/courses/query` accepts (`CourseQuery`). Each clause added only when its value is non-null:

- **keyword**: string — LIKE across `Title`, `OfficialTitle`, `CourseId`, `ProdCourseId`, `FriendlyUrl`.
  (Large text columns `Objective`/`Outline`/`Prerequisites`/etc. excluded — slow, not identifying.)
- **partnerPkid**: `short?` — exact match `Partner_pkid` (dropdown from `lookups/partners`).
- **courseGroupPkid**: `short?` — exact match `CourseGroup_pkid` (dropdown from `lookups/course-groups`).
- **publishStatusPkid**: `byte?` — exact match `PublishStatus_pkid` (dropdown from `lookups/publish-statuses`).
- **scheduleOnFrom / scheduleOnTo**: `DateOnly?` — `ScheduleOn BETWEEN` (inclusive).
- **scheduleOffFrom / scheduleOffTo**: `DateOnly?` — `ScheduleOff BETWEEN` (inclusive).
- **canRepeat**: `bool?` — tri-state exact match `CanRepeat` (null = no filter).

### SQL — SELECT (list / query / get-by-id)

Multi-map over three LEFT JOINs; `splitOn` on each nav object's leading column:

```sql
SELECT c.pkid AS Pkid, c.Title, c.OfficialTitle, c.CourseId, c.ProdCourseId, c.FriendlyUrl,
       c.DisplayOrder, c.Partner_pkid AS PartnerPkid, c.CourseGroup_pkid AS CourseGroupPkid,
       c.PublishStatus_pkid AS PublishStatusPkid, c.ScheduleOn, c.ScheduleOff, c.Hour,
       c.ListPrice, c.LearningCredit, c.Material, c.Objective, c.Target, c.Prerequisites,
       c.Outline, c.TowardCertOrExam, c.Note, c.OtherInfo, c.CanRepeat,
       p.pkid  AS Pkid, p.Name AS Name,                 -- Partner nav
       g.pkid  AS Pkid, g.Description AS Description,    -- CourseGroup nav
       s.pkid  AS Pkid, s.Description AS Description     -- PublishStatus nav
FROM Course c
LEFT JOIN Partner       p ON p.pkid = c.Partner_pkid
LEFT JOIN CourseGroup   g ON g.pkid = c.CourseGroup_pkid
LEFT JOIN PublishStatus s ON s.pkid = c.PublishStatus_pkid
```

- Dapper `Query<Course, PartnerLookup, CourseGroupLookup, PublishStatusLookup, Course>` with
  `splitOn: "Pkid,Pkid,Pkid"`; map nav objects onto `c.Partner/CourseGroup/PublishStatus`
  (null the nav when its pkid is null).
- `GetAllAsync` / `QueryAsync`: `ORDER BY c.DisplayOrder ASC, c.pkid ASC`.
- `QueryAsync` keyword: `(c.Title LIKE @Keyword OR c.OfficialTitle LIKE @Keyword OR c.CourseId LIKE
  @Keyword OR c.ProdCourseId LIKE @Keyword OR c.FriendlyUrl LIKE @Keyword)`.
- `GetByIdAsync`: `WHERE c.pkid=@Pkid`; then two follow-up queries on the same connection to fill
  `CertificationPkids` and `JobCategoryPkids`.

### SQL — INSERT (pkid excluded, IDENTITY)

```sql
INSERT INTO Course (Title, OfficialTitle, CourseId, ProdCourseId, FriendlyUrl, DisplayOrder,
    Partner_pkid, CourseGroup_pkid, PublishStatus_pkid, ScheduleOn, ScheduleOff, Hour, ListPrice,
    LearningCredit, Material, Objective, Target, Prerequisites, Outline, TowardCertOrExam, Note,
    OtherInfo, CanRepeat)
VALUES (@Title, @OfficialTitle, @CourseId, @ProdCourseId, @FriendlyUrl, @DisplayOrder,
    @PartnerPkid, @CourseGroupPkid, @PublishStatusPkid, @ScheduleOn, @ScheduleOff, @Hour, @ListPrice,
    @LearningCredit, @Material, @Objective, @Target, @Prerequisites, @Outline, @TowardCertOrExam,
    @Note, @OtherInfo, @CanRepeat);
SELECT CAST(SCOPE_IDENTITY() AS int);
```

Wrap INSERT + both junction syncs in one transaction (open connection, `BeginTransaction`, pass `tx`
to every command). Use the returned pkid for the junction rows.

### SQL — UPDATE (pkid immutable)

```sql
UPDATE Course SET Title=@Title, OfficialTitle=@OfficialTitle, CourseId=@CourseId,
    ProdCourseId=@ProdCourseId, FriendlyUrl=@FriendlyUrl, DisplayOrder=@DisplayOrder,
    Partner_pkid=@PartnerPkid, CourseGroup_pkid=@CourseGroupPkid, PublishStatus_pkid=@PublishStatusPkid,
    ScheduleOn=@ScheduleOn, ScheduleOff=@ScheduleOff, Hour=@Hour, ListPrice=@ListPrice,
    LearningCredit=@LearningCredit, Material=@Material, Objective=@Objective, Target=@Target,
    Prerequisites=@Prerequisites, Outline=@Outline, TowardCertOrExam=@TowardCertOrExam, Note=@Note,
    OtherInfo=@OtherInfo, CanRepeat=@CanRepeat
WHERE pkid=@Pkid;
```

Then delete-then-reinsert both junctions in the same transaction. Return affected-rows / re-fetch to
detect 404.

### N-N Sync Pattern (create + update, same connection + transaction)

```sql
DELETE FROM CourseInCertification WHERE Course_pkid=@Pkid;
-- per id: INSERT INTO CourseInCertification (Course_pkid, Certification_pkid) VALUES (@Pkid, @CertId);
DELETE FROM CourseJobCategories   WHERE Course_pkid=@Pkid;
-- per id: INSERT INTO CourseJobCategories (Course_pkid, JobCategory_pkid) VALUES (@Pkid, @JobCatId);
```

### DateOnly Type Handlers

`ScheduleOn` / `ScheduleOff` are `date` → C# `DateOnly` via `DateOnlyTypeHandler` (already registered in
`Program.cs` per convention). No `TimeOnly`. No `nchar` on Course itself (only on the `Certification`
lookup Title → RTRIM there).

### Special Column Notes

- `pkid` `int` IDENTITY → excluded from INSERT, read back via `SCOPE_IDENTITY()`.
- `CourseGroup_pkid` nullable → `short?`; null nav object when absent.
- `Outline` / `TowardCertOrExam` are `nvarchar(max)` → no `MaxLength` annotation.
- `ListPrice` `decimal(9,0)`, `LearningCredit` `decimal(9,1)` → both `decimal`.
- `Certification.Title` is `nchar(100)` → `RTRIM()` in the certifications lookup SQL.

### Detail component

- Show all scalar fields; FK fields render as router links (Foreign-Primary Links above).
- N-N: two read-only lists — 對應認證 (certification labels), 對應職務類別 (job-category descriptions),
  resolved by matching `certificationPkids` / `jobCategoryPkids` against the loaded lookups.
- Dates displayed via the `date` pipe (values are `date`, no UTC `+ 'Z'` needed — `DateOnly`).

### Form component

- Reactive Forms; `forkJoin` on init loads all 5 lookups (partners, course-groups, publish-statuses,
  certifications, job-categories); in edit mode also loads the course, then `patchValue`.
- `pkid` — **no field** (IDENTITY); carried internally (0 on create), read from create response for nav.
- Fields: title/officialTitle/courseId/prodCourseId/friendlyUrl `pInputText`; displayOrder/hour
  `p-inputNumber` (`[useGrouping]="false"`); listPrice `p-inputNumber` (`[minFractionDigits]="0"`),
  learningCredit `p-inputNumber` (`[maxFractionDigits]="1"`); partnerPkid/courseGroupPkid/publishStatusPkid
  `p-select`; scheduleOn/scheduleOff `p-datepicker`; canRepeat `p-toggleswitch`/`p-checkbox`;
  material/target `pInputText` or short `textarea`; objective/prerequisites/note/otherInfo `textarea`;
  outline/towardCertOrExam `textarea` (large); certificationPkids/jobCategoryPkids `p-multiselect`
  (`[maxSelectedLabels]="9999"`, `[filter]="true"`).
- **ScheduleOff auto-default**: on `ScheduleOn` `valueChanges`, set `ScheduleOff = ScheduleOn + 10 years`
  (`addYears` from `core/utils/date.util.ts`) with `{ emitEvent: false }`. In edit mode, patch
  `ScheduleOn` before `ScheduleOff` so the loaded `ScheduleOff` wins.
- Date serialization uses local components (`toIso`), never `toISOString()` (UTC+8 off-by-one).
- Sticky `p-toolbar`; required-field validation on the 13 required fields.
